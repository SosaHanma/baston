# Baston de Famille

Jeu de combat en 3D façon PS2, avec toute la famille.

**Jouer :** https://sosahanma.github.io/baston/

## Les combattants
| Perso | Style | Pouvoir |
|---|---|---|
| Moi | Équilibré | Uppercut du Dragon |
| Frère | Costaud | Charge du Taureau |
| Petit frère | Petit et rapide | Pluie de jouets |
| Sœur 1 | Technique | Selfie Flash |
| Sœur 2 | Acrobate | Tornade |
| Les Chats (duo) | Duo agile | Griffes en folie |

Dans l'**Atelier**, chacun peut recevoir sa photo (les chats en ont deux), ses couleurs et un autre pouvoir.
Les photos restent dans le navigateur de chacun : elles ne sont jamais envoyées ni enregistrées dans ce dépôt.

## Commandes
| | Manette | Clavier J1 | Clavier J2 |
|---|---|---|---|
| Bouger / sauter / s'accroupir | Croix ou stick | Z Q S D | Flèches |
| Poing | X / □ | F | K |
| Pied | A / ✕ | G | L |
| Spécial | B / ○ | H | O |
| Pouvoir (jauge) | Y / △ / RB | J | P |
| Pause | Start | Échap | |

Reculer = se protéger. Arrière + bas protège des balayettes.

## Technique
Aucune dépendance : un petit moteur 3D WebGL maison (`js/gl.js`) avec rendu basse résolution et tramage façon PS2.
L'ancienne version 2D est dans [`classic/`](classic/).
