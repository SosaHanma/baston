# Baston de Famille

Jeu de combat dans le navigateur où chaque combattant porte la photo d'un membre de la famille.

**Jouer :** https://sosahanma.github.io/baston/

- 1 joueur contre l'ordi ou 2 joueurs, au clavier ou à la manette
- Un pouvoir spécial par combattant
- Plusieurs décors, dont une photo à soi
- Les photos restent dans le navigateur de chacun : elles ne sont jamais envoyées ni enregistrées dans ce dépôt.

## Commandes manette
Croix / stick : bouger · X : poing · A : pied · B : boule · Y ou RB : pouvoir · Start : pause
